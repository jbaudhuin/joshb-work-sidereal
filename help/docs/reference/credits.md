# Credits &amp; License

## The program

Zodiac began as an open-source charting application by **Artem Vasilev**. This
**sidereal branch** has been developed by **Josh Baudhuin** since 2016, adding the
sidereal ayanamshas, harmonic search, parans and primary directions, the event
engine, and the session and database features described throughout this guide.

## Built on

Zodiac stands on the work of others:

- **[Swiss Ephemeris](https://www.astro.com/swisseph/)** — the astronomical
    library that provides the planetary and house calculations.
- **The Qt framework** — the cross-platform toolkit the application's interface is
    built with.
- **The Almagest and DejaVu fonts** — used for astrological glyphs and text
    throughout the program.
