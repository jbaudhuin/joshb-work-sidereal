# Getting Started

This section takes you from a fresh download to a chart on the screen. If you have never
opened Zodiac before, work through the pages in order; if you are returning, jump to
whichever step you need.

The program is compact and dock-based, and its use model is chart- and table-based
rather than menu-driven. Once it is installed and you have cast a chart, most of the rest
of this guide is about the many ways Zodiac lets you look at that chart and search through
time around it.

- **[Installing Zodiac](installing.md)** — the Windows installer, what it packages, and a
    note for developers building from source.
- **[A tour of the main window](main-window.md)** — the database tree, the toolbar, the
    central tabs, the Events panel, and the status bar.
- **[Creating &amp; editing charts](charts.md)** — casting a chart, the file editor, and the
    chart file types.
- **[Locations, time &amp; calendars](location-time.md)** — place lookup, time modes, and
    historical-date handling.
