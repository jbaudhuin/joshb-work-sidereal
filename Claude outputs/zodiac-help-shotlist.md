# Zodiac help site — screenshot shot-list

**49 screenshots across 39 pages.** Capture these however you like; I'll crop, size, and wire them into the site.

## How to do these

- **Use one neutral demo chart** for everything that shows a chart — a well-known public figure (published birth data) or a made-up chart — **not** real family/client data, since the site will be public. Keep the *same* demo chart across all shots so the site looks consistent.
- **Maximize the window** for full-window shots. A few shots are close-ups (a toolbar, a dialog, the status bar) — just crop loosely; I'll tighten them.
- **Dark theme** for everything **except** the two Themes shots (one dark, one light of the same chart).
- **Format:** PNG preferred. Resolution doesn't matter — bigger is fine, I'll downscale.
- **Naming:** save each with the exact `filename` shown (easiest), *or* just number them `01.png`, `02.png`, … in the order listed here and I'll map them — either works.
- **Where to put them:** drop them all in one folder — e.g. make a `help-screenshots` folder in your `joshb-work-sidereal` repo — and tell me when a batch is ready. You can do them in any order, a few at a time.
