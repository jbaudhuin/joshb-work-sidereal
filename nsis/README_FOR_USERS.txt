ZODIAC SIDEREAL - Astrological Software
Version 0.9.8.2
========================================

ABOUT
=====
Zodiac Sidereal is a comprehensive astrological charting application featuring:
- Sidereal zodiac calculations (Fagan-Bradley and Lahiri ayanamshas)
- Harmonic charts and analysis
- Transit calculations
- Primary directions and parans
- Paranatellonta event finding ("paransits")
- Fixed star conjunctions and parans
- Declination strip view
- Bi-wheel prime vertical display ("mundoscope")
- Event search and timing
- Multiple chart types and display options

This is a specialized fork focusing on sidereal and harmonic astrology practices.

GETTING STARTED
===============
1. Run zodiac.exe after installation
2. Create a new chart: File > New
3. Enter birth data (date, time, location)
4. Explore different views using the tabs and dock panels
5. Sample celebrity charts are included in the installation

MAIN FEATURES
=============
- Chart wheel with customizable display
- Harmonic aspect patterns (H1-H32)
- Transit and progression tracking
- Speculum and parans calculations
- Event search with multiple criteria
- Export charts and data
